# Give each logical device a WAN address

Now the supervisor should address gateway-owned aliases, rather than the devices' private addresses:

| Supervisor connects to | Gateway translates destination to |
|---|---|
| 192.0.2.10:10000 | 10.20.0.11:10000 (LD1) |
| 192.0.2.11:10000 | 10.20.0.12:10000 (LD2) |

Add the aliases and destination NAT rules **inside the gateway namespace**:

```bash
ip -n lab-gw addr add 192.0.2.10/24 dev eth1
ip -n lab-gw addr add 192.0.2.11/24 dev eth1
ip netns exec lab-gw iptables -t nat -A PREROUTING -i eth1 -d 192.0.2.10 -p tcp --dport 10000 -j DNAT --to-destination 10.20.0.11:10000
ip netns exec lab-gw iptables -t nat -A PREROUTING -i eth1 -d 192.0.2.11 -p tcp --dport 10000 -j DNAT --to-destination 10.20.0.12:10000
ip netns exec lab-gw iptables -A FORWARD -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
ip netns exec lab-gw iptables -A FORWARD -i eth1 -o eth0 -d 10.20.0.0/24 -p tcp --dport 10000 -j ACCEPT
ip netns exec lab-gw iptables -P FORWARD DROP
printf '192.0.2.10\n192.0.2.11\n' > logical_devices.conf
ip netns exec lab-sup python3 supervisor.py
```{{exec}}

Connection tracking reverses the translation for replies. Source NAT is unnecessary here: LD1 and LD2 already route replies through the gateway. Remove those return routes and the request can arrive while its reply fails.

Inspect the packet path in a second terminal:

```bash
ip netns exec lab-gw timeout 15 tcpdump -l -ni any 'tcp port 10000'
```{{exec}}

While the capture runs, run `ip netns exec lab-sup python3 supervisor.py` in the first terminal. Compare the destination on `eth1` with the destination on `eth0`. Then inspect counters:

```bash
ip netns exec lab-gw iptables -t nat -nvL PREROUTING
ip netns exec lab-gw iptables -nvL FORWARD
```{{exec}}

NAT chain counters count the initial packets that establish translations, not every packet in an established connection. Filtering and address translation serve different purposes. These lab rules allow the status service; they are not a complete substation security architecture.
